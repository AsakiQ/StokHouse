# Stok House 0.1.0-alpha

Stok House добавляет совместное проживание в Stardew Valley 1.6.15. Сборка рассчитана на Steam, Windows 10/11 x64 и SMAPI 4.5.2. Мод и установщик скомпилированы. Проверка в Stardew Valley и запуск интерфейса установщика на Windows ещё впереди. Для первой игры используйте **новую тестовую ферму** или копию сохранения.

Требования и критерии готовности описаны в [техническом задании](docs/WORK_BRIEF.md).

## Установка

1. Закройте Stardew Valley. Распакуйте общий архив, затем каждому игроку запустите `StokHouseSetup.exe`. Если установщик не нашёл игру, выберите папку, в которой находится `Stardew Valley.exe`.
2. Нажмите **«Установить Stok House»**. При отсутствии совместимого SMAPI установщик скачает его из официального выпуска и проверит SHA-256. Подпись Windows у EXE отсутствует.
3. Нажмите **«Копировать строку»** и вставьте её в **Steam → Stardew Valley → Свойства → Общие → Параметры запуска**. Если там уже есть рабочая строка для SMAPI, оставьте её. Если есть свои параметры, сохраните исходную строку перед правкой.
4. Запускайте Stardew Valley через кнопку **«Играть»** в Steam. У всех пятерых должна быть одна версия Stok House. SinZational Shared Spaces для этой сборки не нужен.

Если SMAPI уже установлен, можно распаковать `package/StokHouse-mod.zip` в игровую папку `Mods`. В итоге `manifest.json` должен лежать прямо в `Mods/StokHouse`. Параметры запуска Steam остаются такими же, как при автоматической установке.

## В игре

- **F8 → Предложить жить вместе.** Владелец видимого дома выбирает игрока. Получатель принимает или отклоняет запрос во всплывающем окне. Запрос действует три минуты. Исходящий запрос можно отменить.
- **F8 → Вернуться в собственный дом.** Для переезда к другому владельцу достаточно принять новое приглашение. Если у игрока уже есть жилец, сначала этот жилец должен выехать. Хост остаётся владельцем главного дома.
- **F8 → Права жильцов.** Владелец может разрешать изменение интерьера и выбирать режим улучшений. По умолчанию у жильца есть доступ к интерьеру, а заказ Робин требует подтверждения.
- **Робин → Улучшить общий дом.** По запросу жильца игра показывает стоимость. Владелец подтверждает и оплачивает заказ. В совместном режиме с общим кошельком запрос запускается без отдельного подтверждения, а материалы берутся из инвентаря владельца. Раздельный кошелёк всегда требует согласия владельца. Стандартные три улучшения включены. Перепланировка и перенос комнат остаются в меню владельца.
- **Почта.** Оба жильца нажимают на ящик своего дома. Игра открывает письма и награды персонажа, который взаимодействовал с ящиком.
- **Сон.** В тестовой ферме сначала поставьте по кровати на человека. Поведение одной двуспальной кровати для двух игроков входит в игровую проверку.
- **Сохранение.** После изменения жилья завершите игровой день. Игровые слоты и содержимое технических домиков сохраняются. Место скрытого домика остаётся зарезервировано под его возвращение. Содержимое этого домика снова доступно после выезда жильца из общего дома.

Поддержка расширенных сценариев с NPC-супругами, детьми и модами, меняющими дома, остаётся непроверенной. Клавишу и лимит жильцов можно поменять в `Mods/StokHouse/config.json`. На хосте `Capacity` по умолчанию равен 2.

## Файлы и пересборка

| Файл или папка | Содержимое |
| --- | --- |
| `StokHouseSetup.exe` | Windows-установщик с вложенной версией мода |
| `package/StokHouse-mod.zip` | Раздельная установка мода |
| `package/modpack.json` | Версии и контрольные суммы зависимостей и файлов мода |
| `StokHouse_Source/` | Исходники мода и проверок логики проживания |
| `StokHouseSetup_Source/` | Исходники установщика и проверок файловых операций |
| `docs/` | Инструкция хосту, отчёт и восстановление |

Для разработки нужны .NET SDK 8, Python 3 и игра с SMAPI. Из PowerShell выполните `./build.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Stardew Valley"`. Мод рассчитан на игровой .NET 6. Результаты пересборки появятся в `package/`. Установщику на компьютере игрока SDK и Python не нужны.
