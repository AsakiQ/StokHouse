# Stok House

**Stok House** — проект оригинального SMAPI-мода для Stardew Valley и установщика **StokHouseSetup.exe**.

> Статус: подготовка проекта. Рабочий мод и установщик пока не разработаны и не протестированы.

## Цель

Совместное проживание игроков на стандартной Beach Farm (пляжная ферма) при сохранении независимых персонажей:

- 5 игроков и 3 видимых дома: хост с партнёром в главном доме, вторая пара в домике, один игрок в отдельном домике.
- Внутриигровые приглашения съехаться, согласие адресата, выезд и смена дома.
- Совместное использование интерьера и разрешённое управление улучшениями дома.
- Один видимый почтовый ящик дома, но персональные письма и награды для каждого персонажа.
- Корректное сохранение, сон, переподключение и стандартные Steam-приглашения.

При необходимости должны сохраняться невидимые технические домики, если этого требует игровой движок. Безопасность сохранений важнее визуальных изменений.

## Компоненты

1. **Stok House** — собственный SMAPI-мод на C#.
2. **StokHouseSetup.exe** — однократный Windows-установщик SMAPI и модификации. **Не игровой лаунчер**: после установки Stardew Valley запускается обычной кнопкой «Играть» в Steam.
3. **GitHub Releases** — распространение протестированных сборок и установка совместимой версии с проверкой контрольных сумм.
