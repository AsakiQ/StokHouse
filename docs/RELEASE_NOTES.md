# Stok House v0.1.4-beta.1 — public beta candidate

**Not yet published.** This release must be approved by the project owner and marked **Pre-release**.

Совместимость: Stardew Valley **1.6.15**, SMAPI **4.5.2**, Steam, Windows 10/11 x64.

### Возможности
- Совместное проживание игроков без игровой свадьбы: приглашение и подтверждение через **O**.
- Скрытие лишней гостевой хижины с сохранением данных для возвращения.
- Раздельная почта в одном домашнем ящике и права жильцов.
- Запрос улучшения общего дома у Робин с оплатой заказчиком при раздельных кошельках и подтверждением владельцем в необходимых режимах.
- Windows-установщик, проверка вложенных файлов, резервные копии, восстановление.
- Открытый исходный код Stok House по **MIT**. Уведомления о сторонних компонентах: `THIRD_PARTY_NOTICES.md`.

### Что НЕ включено
- **Экспериментальные семейные бюджеты** из `feature/family-budget` (объединение/разделение денег, общие покупки): в этой бете их **нет**.
- Гарантированная поддержка всех модов, которые меняют дома, и всех сценариев с NPC-супругами/детьми.

### Известные риски и обратная связь
- Альфа-сценарии проживания и улучшения дома тестировались в Steam на двух ПК, но массовые тесты на 5–7 игроков и расширенные сценарии ещё не завершены.
- Возможны ошибки совместимости и сохранений: **используйте отдельную ферму или проверенную резервную копию**.
- Версии мода у всех участников должны совпадать. При проблеме пришлите версию игры/SMAPI/мода, последовательность действий и журналы SMAPI с обоих компьютеров.
- Windows EXE не подписан сертификатом издателя; сверяйте `SHA256SUMS.txt`.
- Перед удалением мода верните жильцов в собственные дома и сохранитесь (см. `docs/RECOVERY.md`).
