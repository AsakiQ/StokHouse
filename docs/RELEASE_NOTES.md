# Stok House

Stok House 0.1.2-alpha для Stardew Valley 1.6.15 и SMAPI 4.5.2. Включает Windows-установщик x64, архив мода и файлы проверки целостности.

У второго жильца в мастерской Робин появляется **«Улучшить общий дом»**, когда заказ доступен. После выбора открывается предложение со стоимостью. Когда общий заказ недоступен, сохраняются штатные действия Робин. Повторная доставка того же разрешения не запускает вторую покупку.

Перед распространением проверьте в кооперативе оба режима управления, списание золота и материалов и начало строительства у нужного владельца. Подробности в `StokHouse-docs.zip`.
