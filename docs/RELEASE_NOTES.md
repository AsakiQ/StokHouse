# Stok House

Stok House 0.1.1-alpha для Stardew Valley 1.6.15 и SMAPI 4.5.2. Включает Windows-установщик x64, архив мода и файлы проверки целостности.

Исправлена ошибка инициализации при выборе перегрузки `Game1.getCharacterFromName`. Меню открывается английской **O**. При первом запуске старый F8 мигрирует на O с сохранением остальных настроек, а уже настроенные другие клавиши продолжают работать.

Перед распространением проверьте сон, почту, улучшения дома и схему 2+2+1 на новой пляжной ферме с пятью Steam-клиентами. Подробности в `StokHouse-docs.zip`.
