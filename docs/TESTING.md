# Отчёт о проверке

## Что выполнено

Всего 57 автоматических проверок, включая 16 сценариев оплаты и восстановления и 8 регрессий диалога Робин. Игровые типы в регрессионных тестах заменены тестовыми реализациями, патчи применяет библиотека Harmony из SMAPI 4.5.2.

| Проверка | Результат |
| --- | --- |
| Компиляция Stok House | На .NET 6 по двоичным файлам официального SMAPI 4.5.2 для Windows. Пакет содержит две DLL, манифест и русскую локализацию. |
| Логика домохозяйств | 10 автоматических проверок. Распределение 2+2+1, права отправителя и получателя, конфликт приглашений, отмена, тайм-аут, лимит, выезд, повторные операции, сохранение правил и проверка некорректных данных. |
| Инициализация на тестовых сигнатурах | Старый вызов реальной библиотеки Harmony воспроизводит `AmbiguousMatchException`. Новый код выбирает необобщённый `Game1.getCharacterFromName(string, bool, bool)`, проверяет перегрузки и устанавливает 22 патча на тестовых типах. |
| Диалог Робин | С Harmony из SMAPI воспроизведён сбой 0.1.1-alpha. Замена элемента `__args` не передавала новый массив в штатный диалог. Затем старый обработчик поглощал `carpenter_Upgrade`. Исправление проверено для обоих вариантов отрисовки, штатных кнопок и отказа после выбора. |
| Оплата общего улучшения | Проверены раздельный и общий кошельки, списание материалов у заказчика, чек владельца и его таймер, цены трёх ступеней, нехватка ресурсов, два конкурирующих заказа, повтор фаз, отмена, отключение участников, загрузка журнала, возврат при полном инвентаре и откат при отказе записи. |
| Настройки | Проверены новая клавиша O, миграция старого F8, сохранение дополнительных полей, собственные привязки и восстановление значения по умолчанию при ошибке чтения. |
| Ядро установщика | 13 автоматических проверок на временной файловой структуре. Поиск отдельной библиотеки Steam, установка из подлинного Windows-пакета SMAPI без сети, копии, повторная установка, контрольная сумма, конфликт, откат и удаление. |
| Windows EXE | Собран как самостоятельное приложение x64. GitHub Actions запускает EXE на Windows и проверяет встроенный архив, SHA-256 и манифест через `--verify-package`. |
| Stardew Valley и Steam | На стенде не было установленной игры и пяти Steam-клиентов. Остаются проверка диалога и оплаты в Steam-кооперативе, а также игровой сценарий на пяти клиентах. Можно проверить сигнатуры реальной игровой сборки без запуска игры командой `./build.ps1 -Test -SkipSetup -GamePath "D:\SteamLibrary\steamapps\common\Stardew Valley"`. |

## Сценарии на новой Beach Farm

| Проверка | Ожидаемый результат |
| --- | --- |
| 1. Запуск и вход пяти игроков | В SMAPI появляется `Stok House ready`. После загрузки фермы английская O открывает меню. Пять разных персонажей подключаются через Steam. |
| 2. Распределение 2+2+1 | После двух принятых приглашений видны три дома. Пять персонажей остаются доступны. |
| 3. Приглашение | Получатель видит имя инициатора и действия «Принять», «Отклонить». Отдельно проверить отмену в меню, открытом клавишей O. |
| 4. Принятие | Игрок оказывается в общем доме. Его первоначальный домик скрывается. |
| 5. Мебель | Жилец ставит и перемещает мебель, владелец видит результат. После запрета попытка жильца отклоняется. |
| 6. Робин | Жилец запрашивает улучшение у Робин. Владелец одобряет. При раздельных кошельках меняются баланс и материалы заказчика. При общем меняются общий баланс и материалы заказчика. Через три игровых дня меняется нужный дом. Повторить в обоих режимах, сначала в доме хоста, затем в домике другого клиента. Проверить отказ при нехватке золота и материалов и два конкурирующих заказа. Отдельно нажать улучшение собственного домика на персонаже, у которого нет доступного общего заказа. |
| 7. Почта | Два жильца открывают один ящик. Каждый получает своё письмо, предмет или рецепт. Отдельно проверить одинаковое письмо у обоих и прочтение одним при офлайне другого. |
| 8. Дом Лии | Дом Лии работает так же, как главный дом. |
| 9. Дом Ярика | Ярик живёт в своём домике и получает личные письма. |
| 10. Сон | Все пятеро завершают день. Проверить две кровати, отключение одного игрока и отдельно использование двуспальной. |
| 11. Сохранение | После ночного сохранения инвентарь, навыки и задания всех пяти персонажей сохранены. |
| 12. Переподключение | Сначала перезапустить клиента в тот же день, затем хоста после ночного сохранения. Проверить дома, почту и права. Во время заказа раздельно отключить заказчика и владельца на этапах получения материалов и запуска стройки, повторить с ночным сохранением и перезапуском хоста. Сверить остатки и таймер после входа. При возврате с полным инвентарём освободить место. |
| 13. Смена дома | Игрок принимает новое предложение или возвращается в свой дом. Прежний дом освобождается, личная почта и инвентарь доступны. |
| 14. Восстановление | Возврат всех в свои дома, удаление мода, загрузка сохранённой фермы. Отдельно восстановить копию после имитации сбоя. |

Для установщика на Windows проверьте Steam на другом диске, ручной выбор пути, запуск EXE без SDK, копирование строки в буфер, доступ без прав записи, ошибку сети без кэша, повторную установку и откат после прерывания.

Для диагностики проблем у Робин найдите строки `[Stok House] Robin:` в `%AppData%\StardewValley\ErrorLogs\SMAPI-latest.txt` у жильца и владельца. В них указаны исходные кнопки, маршрут, идентификатор заказа, участники, подтверждения этапов, изменения золота и отключения. Stok House не вызывает Steamworks или API лобби. Связь разового предупреждения Steam с заказом не подтверждена. Для сопоставления нужны журналы SMAPI хоста и клиента за один сеанс с временем предупреждения.
