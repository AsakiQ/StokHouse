# Stok House — рабочее техническое задание для ChatGPT Work

**Репозиторий:** `AsakiQ/StokHouse` (private). **Ветка:** `main`.

Полный мастер-промпт находится в чате пользователя. Этот файл фиксирует главные требования; при различиях нужно уточнять у пользователя, а не предполагать.

## 1. Целевое окружение
- Актуальная стабильная Stardew Valley для Windows 10/11 через Steam.
- Подходящие версии SMAPI и .NET — определить по официальным источникам.
- Игроков 5; отдельные компьютеры и Steam-аккаунты; хост запускает кооперативную ферму.
- **Стандартная Beach Farm**, не Riverland Farm.
- Три **видимых** жилых дома: хост + партнёр, вторая пара, отдельный игрок.

## 2. Собственный SMAPI-мод Stok House
- **Писать собственный мод.** Чужие моды (включая SinZational Shared Spaces) изучать как техническую справку, соблюдая авторские права и лицензии.
- Сохранить за каждым отдельным игроком техническую привязку, уникальный ID, инвентарь, навыки и прогресс. Если движку нужны дополнительные скрытые домики — оставить их безопасно.
- Внутриигровые приглашения на переезд: отправить, принять, отклонить, отменить, выехать. Совместное проживание не требует свадьбы.
- Общий дом: сон, вход, мебель и интерьер, права жильцов; улучшения у Робин — безопасная делегация операции, авторитет хоста, согласование стоимости/прав и запрет двойных списаний.
- Общий физический почтовый ящик, но **раздельные** персональные списки писем, отметки прочтения, вложения и награды; при смене дома почта следует за персонажем.
- Мультиплеерная синхронизация и сохранение состояния; обработка переподключения, конфликтов и отмены операций. По умолчанию два жильца на дом.
- Отдельная локализация RU; предусмотреть расширение на другие языки.

## 3. Windows-установщик
- Название: `StokHouseSetup.exe`.
- Находит Steam, библиотеки и Stardew Valley, проверяет версии, устанавливает подходящий SMAPI и Stok House из доверенных источников.
- Настраивает/помогает настроить SMAPI для запуска **через обычную кнопку Steam «Играть»**.
- **Никакого отдельного лаунчера**, постоянной фоновой службы или запроса Steam-паролей.
- При необходимости спрашивает согласие на опасные изменения, резервирует сохранения и настройки, позволяет проверить/восстановить/удалить сборку.
- Модпак фиксирует версии/зависимости и SHA-256; релизы в GitHub используются для распространения с проверкой целостности. Без самовольных обновлений при старте игры.
- Учитывать ограничения Nexus и лицензии сторонних файлов. Не обходить авторизацию.

## 4. План и проверка
1. Исследовать официальные API Stardew Valley/SMAPI, жизненный цикл домиков и почты; зафиксировать неизвестные и риски.
2. Реализовать минимальную вертикальную версию: 5 персонажей, 3 видимых дома, приглашение и сохранение.
3. Расширить до общих прав, улучшений, индивидуальной почты, сна и сетевой синхронизации.
4. Добавить модульные тесты логики и сериализации; компилировать против фактически существующих API, не придумывать сигнатуры.
5. После выбора финального состава модов создать установщик; выполнить проверки установки, повторного запуска, резервного копирования.
6. Подготовить исходники, инструкции, журнал тестов, GitHub Actions для сборки, а затем безопасный процесс публикации Releases.

**Критерии игровых проверок:** пять игроков подключены, три видимых дома на Beach Farm; две пары принимают приглашения; мебель и улучшения работают без дублирования платежей; почта у каждого отдельная при одном ящике; сон, переход дня, сохранение, переподключение, выезд не теряют данные.

## 5. Правила качества
- Не выдавать проект-заглушку за готовый мод или установщик.
- Не называть сборку или проверку «пройденной», если она фактически не выполнялась.
- Игровые тесты на пяти ПК обозначать как ручные, пока они не выполнены.
- Сохранность данных — первоочередная. При техническом риске остановить опасную операцию и объяснить альтернативу.
- Репозиторий сохранить **приватным**; не публиковать публично без одобрения.
- Коммитить последовательные работающие изменения; не включать токены, приватные данные и игровые сохранения.
