# Сборки и релизы Stok House

## Сборка разработчика

Установите .NET SDK 8, среду выполнения .NET 6, PowerShell 7 и Python 3. Команда `./build.ps1 -Test` скачивает закреплённый официальный архив SMAPI, сверяет SHA-256, компилирует мод, запускает оба набора проверок и собирает Windows x64 EXE. Такой сценарий работает без установленной игры. Можно указать локальный архив аргументом `-SmapiArchive` или собрать мод по установленному SMAPI аргументом `-GamePath`.

После сборки `python package/release.py` упакует файлы для распространения в `.artifacts/release`. Контрольные суммы мода и закреплённые версии находятся в `modpack.json`. Контрольные суммы скачиваемых файлов находятся в `SHA256SUMS.txt`.

## Сборки GitHub Actions

На каждый push в `main` и pull request, направленный в `main`, запускается **Build Stok House**. После компиляции и проверок Windows runner запускает EXE с аргументом `--verify-package` для проверки вложенного мода. Файлы доступны в артефакте `StokHouse-Windows-x64` на странице запуска. Артефакт доступен участникам приватного репозитория.

## Черновик GitHub Release

1. Откройте **Actions → Build Stok House → Run workflow**, оставьте ветку `main` и включите `draft_release`.
2. После зелёной сборки GitHub создаст черновик предварительного релиза с тегом из версии мода, например `v0.1.0-alpha`. В черновике будут EXE, ZIP мода, манифест модпака, контрольные суммы, инструкции и лицензии среды выполнения.
3. Перед распространением проверьте [игровые сценарии](TESTING.md). Через веб-интерфейс Releases можно опубликовать проверенный черновик в приватном репозитории для пользователей с доступом. Репозиторий остаётся приватным. Повторный запуск с тем же тегом не перезаписывает существующий релиз.

Для обновления выберите нужный релиз и запустите его установщик вручную. Установщик проверяет вложенный мод по контрольным суммам, сохраняет конфигурацию и делает копию перед заменой. Игрокам не нужно давать EXE доступ к GitHub. Чтобы скачать файл напрямую из приватного Releases, у аккаунта игрока должен быть доступ к репозиторию.
